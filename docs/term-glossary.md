# Term Glossary

- **API**: Software interface for submitting lending instances and obtaining lending matches. The API system allows lenders to provide lending instances and consume consumer matches.
- **Consumer Match**: The relationship between a Lending Instance submitted by your organization and lending instances submitted by another organization. A consumer match is the outcome of the Clearlinc system.
- **Consumer State**: The performance state of the lendee's credit outcome.
- **Credit State**: The lifecycle state of the lendee's credit product.
- **Data ETL**: An alternative to API Steps 1 & 2 that automates the submission of lending instances from a lender's org into the Clearlinc system.
- **Lending Instance**: The assembly of Loan Facts, Credit State, and Consumer State. A lending instance is the input to the Clearlinc system.
- **Loan Facts**: Information on the lendee and the loan or potential loan to which the lendee will/is granted.
- **Webhooks**: Software interface for realtime updates for lending matches.
